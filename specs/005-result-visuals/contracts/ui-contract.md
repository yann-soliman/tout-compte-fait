# UI contract

Display visual cards inside results, after result heading and before existing detailed numbers.
Waterfalls: “Du brut à la valeur économique”, Micro/Salariat columns, shared axis/zero line, named amounts, loss visible; annual/monthly labels track period. Economic result and difference remain text, fees/benefits separate.
Map: “Trouver une zone d’équilibre”, violet favors micro / green favors employee, neutral around balance, gray hatching outside ceiling. Annotate current scenario and equilibrium line; axes TJM €/j and billed days/year. Native day/rate controls + selected annual detail + explicit “Appliquer cette hypothèse”; disable non-applicable values and label why. State historical eligibility limitation and annual before-tax/excluding-retirement assumption.
Responsive: single column on mobile, no page overflow, readable text values at all widths; only supporting detail may be collapsed. Screen reader equivalents and no hover-only critical content. Colors have labels; current/ceiling/balance differentiated by marker/dash/hatch too.
