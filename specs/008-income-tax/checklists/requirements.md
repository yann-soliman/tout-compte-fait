# Specification Quality Checklist

- [x] Valeur utilisateur et périmètre bornés.
- [x] Exigences, scénarios et critères mesurables.
- [x] Aucun besoin de clarification bloquant ; hypothèses documentées.
- [x] Risques année fiscale, cash/base, déficit, foyer et stockage explicités.
- [x] Aucun détail technique imposé dans les exigences.
- [x] Hors périmètre identifié ; pas de panel humain.

La checklist atteste la qualité documentaire, pas une implémentation ni une validation.
